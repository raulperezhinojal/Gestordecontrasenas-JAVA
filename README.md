
# Gestor de contraseñas 
Gestor de Contraseñas

Este proyecto es una aplicación sencilla en Java que permite a los usuarios gestionar sus contraseñas de forma segura. Incluye funcionalidades para generar, guardar, consultar y eliminar contraseñas asociadas a diferentes servicios.

Características

Generación de contraseñas: Permite crear contraseñas seguras con opciones de longitud personalizable, inclusión de números y símbolos.

Almacenamiento de contraseñas: Guarda contraseñas junto con una descripción o nombre del servicio para su posterior consulta.

Consulta de contraseñas: Muestra todas las contraseñas almacenadas, indicando el servicio asociado.

Eliminación de contraseñas: Permite eliminar contraseñas almacenadas mediante el nombre del servicio
